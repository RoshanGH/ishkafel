产品负责人的要求：**按一个高水准苹果软件产品经理的标准，把这个产品做到
「可以直接拿去卖」的品质**，UI / UX / 性能都要到 9 分；打分维度自己定。

打包这一环（凭据注入）本轮不动。

## 二、这一轮改了什么

### 空间与布局

- **审片台三栏重新分配**：1440 窗口下中栏 775px 里画面只占 211px，
  两侧 560px 是纯黑，而左栏的台词被截断、右栏表单挤成一团。现在属性面板
  也吃这片空间（原来只有挑素材时才吃），左右栏各到 480，死黑降到 270。
- **第六条轨（音频波形）原来整条在可视区外**：时间线区写死占 44%，
  1440×900 下给得出 350px，而六条轨加工具条要 370px。改成按内容算高度、
  上下用 55%/35% 夹住——现在任何允许的窗口尺寸下六条轨都完整可见。
- 任务卡高度对齐：空白任务没有「等了多久/花了多少」那一行，整块信息区
  往下掉，一排卡片里只有它是歪的。
- 播放控制条：窄栏下时间码被横向滚动推出可视区（显示成「00:00.00 / 01:1」）。
  改成 Wrap，放不下就换行，时间码永远完整；再窄先舍「跳到片头/片尾」。
- 缩放滑杆原来用 `Expanded` 撑满整条工具条一千多像素，屏幕上是「最左一个
  小蓝点、最右一个孤零零的放大镜」。收到 160 并靠右，顺手加「铺满窗口」。
- 导出对话框的表单控件（「1080P」「30fps」）原来铺满 940px 一整行。
- 审核页台词一行 1100px（100 多个汉字），收到 720。
- 设置页内容整块居中——1440 窗口里 640 的内容贴着左边导航栏，右手边空 580。

### 视觉一致性

- 预览画面加发丝边 + 落影，中栏底色沉一级：深色画面不再和背景连成一片。
  编导台同步。
- **文字对比度到 WCAG AA**：`textTertiary` 在卡片底上原来只有 2.33:1
  （正文要求 4.5:1），而它在全项目两百多处、很多是「要读的说明」。
  整体上移一档并加了对比度守卫测试——守的是性质，不是色值。

### 信息层级

- 属性面板的空状态从一句「未选中任何单元或镜头」变成**整片概览**：
  多长、几个单元几个镜头、换过画面的镜头几个、改过几处字幕、换过几个音色。
- 时间线四条轨的操作说明原来常驻（「拖两端改长度，点 × 删除」之类），
  一屏四行灰字。改成停在哪条轨上才出那条。
- 顶栏标签组：两层选同一套组时会把十个名字拼成一串、后五个跟前五个一样。
  现在说「标签组 A / B · 两层同一套」或「单元 A · 镜头 B」。
- 「因子 = 1 × 1 × 1 × … = 1」（13 个镜头一个没挑）→「还没挑素材，
  这一段照原片播」；状态栏的组合数只点名真的挑了素材的单元。

### 操作效率

- 快捷键（JKL 走带、⇧←→ 一次 10 帧、Home/End）实现了却没地方查。
  抽成唯一一份清单，审片台按 `?` 或 ⌘/ 随时叫出来，帮助弹窗引用同一份；
  架构测试盯着「说得出的键真的绑上了」。
- 补全所有图标按钮的 tooltip，播放键的 tooltip 里带快捷键；加守卫。
- 首页任务卡加 hover 反馈和手型光标——它是门面，原来鼠标移上去毫无反应。

### 反馈与状态

- 导出对话框「共 0 条成片」+ 灰掉的按钮，不说为什么。真实原因是两个位置
  挑了同一条素材（一条成片里不允许同一条出现两次），每一种排法都被丢掉。
  现在点名「素材 116719 同时用在 U1·S7 和 U3·S1」。
- 审核页候选缩略图缺失时只有一个胶片图标，分不出「还没抽到帧」和「文件没了」。
- 配乐轨空着时什么都不说，现在说「还没加配乐——横向拖选一段就能加」。
- 分析失败原来用 SnackBar：文字选不中、几秒后消失，而里面常带着 ffmpeg
  的原文。改成对话框 + 可选中复制。导出失败同理。

### 性能

- **进一次审片台换了 6 次画面源**（真机日志），每次都是 mpv 重开文件：
  先按原片铺一版、每渲好一段切片补一版、代理好了再整体换一版。
  现在排队时只留最后一版，加上切片就绪通知的合并窗口，**降到 3 次**
  （初始 / 切片就绪 / 代理就绪，这是合理下限）。
- **缩略图全部按图片自己的分辨率解码**：全项目 11 处 `Image.file` 没有一处
  限制解码尺寸。盘上的缩略图是 360×640 / 270×480，一张解成 RGBA 是
  0.5~0.9MB，而挑中托盘里那格只有 13pt 宽。收敛成 `ThumbImage`
  （按控件实际像素宽解码）并加守卫。
- 时间线胶片条解码 270×480 且**常驻内存**（握到离开页面），二十几张约 13MB，
  而格子只有 52px 高——按格高解码后约 0.6MB。
  实测审片台常驻 236MB（首页 132MB），大头是 mpv 解码器与视频纹理，
  这一项省下的是其中十几 MB。
- 启动时「清孤儿产物」挡在 `runApp` 前面 await（读全部任务 + 扫产物目录），
  人点了图标只能对着 Dock 等。挪到后台；物料迁移仍然挡在前面（它改的是
  素材落地位置，UI 读到路径之前必须做完）。

### 文案

- 「因子」「1 × 1 × 1」这类内部说法清掉（见上）。
- 项目组标签「未设项目组 · 搜的是我的全部项目」在那一行放不下、被截成
  「…搜的是我的...」——一个要求刺眼的警示正好被咬掉。改短并把完整的话
  搬进 tooltip。
- 候选面板空状态从「选择一种检索方式」改成指名道姓「点上面的『标签』…」。

### 第二批（真机逐页复看之后）

- **属性面板的「拆分 / 并入」原来永远看不到**：时间、锁定说明、标签、音色、
  台词框加起来早超过一屏，这两个按钮排在最后，跟着滚就落在可视区外。
  现在钉在面板底部；那段四行的锁定解释也压成一行（原因进 tooltip）。
- **新建向导的最后一个输入框被底部说明压掉一半**：对话框高度写死 640，
  而屏幕有 900。改成跟着屏幕走（上限 820），耗时说明从两行压成一行。
- 新增 `ScrollFade`：内容没到底时下沿压一层淡出。macOS 的滚动条是
  overlay 式的，不动鼠标根本不出现——没有它，人不知道下面还有东西。
  用在属性面板、新建向导、设置页。
- 左栏上限 560（右栏仍 480）：那一栏是台词，宽一点就多显示半句；
  两个上限再随窗口宽度放开（1440 这档不受影响）。
- 缩放滑杆的未走过段落原来是隐形的，屏幕上只剩一个孤零零的蓝点。
- 拼片任务的整片概览不再显示「换过画面的镜头 0 / 0」——它没有镜头层，
  该说的是「已挑到素材的分子 1 / 5」。
- 拼片里「U2…还没选素材」的横幅右边原来摆着一个「重试」——那件事重试
  一百次也不会变。只有「取不到配乐」这类外部抖动才给重试。
- 候选面板：加载转圈现在说自己在按什么找；顶部那行提示挤了三条独立信息
  还截断，末尾标出「共 N 条」。
- 运行环境页 `audio-separator` 折成两行，标签列加宽。
- 时间线的光标现在说得出「这儿能干什么」：压在边界手柄上是双向箭头、
  压在刻度尺上是拖播放头，别的地方保持普通箭头。
- 窄镜头块不再画描边：1px 描边在 4px 宽的块上占一半面积，十几个挨在一起
  就是一片条形码。
- 底部三个出口（审核候选 / 剪映 / 进入矩阵导出）加说明——「剪映」点下去
  就开始归集素材、生成几百 MB 的工程，按钮上却只有两个字。
- 顺手修了一条 flaky 测试：`agent_stage` 用墙钟量「有没有少等几次超时」，
  并发跑时机器一忙就假红（撞到三次）。改成数次数，性质本来就是次数。

### 第三批（编导台）

产品负责人提醒：**脚本成片这条线不用上传参考视频**（「台词自己写，也可以
进编导台后上传一条参考片」）——我先前判断成「进去就要花额度」是错的。
建一条空脚本任务、用 CLI 灌几行台词进去，就能免费走查整条编导台。

- **「未进预览」的原因被抄了四遍**：四行台词都没配音，中栏就摞了四条橙字，
  一模一样只有行号不同。原来的规则是「不超过 4 行就逐条点名」——该省的
  从来不是行号，是重复的那句原因。改成先按原因归堆、行号并成区间：
  「第 1–4 行未进预览：还没生成配音」。不连的行不许并（会冤枉中间那行）。
- **预览画面的边在「黑压黑」上等于不存在**：画面是纯黑、舞台底色也接近黑，
  中间那条白 9% 的普通描边完全看不见，人看不出画幅到哪儿为止。
  给舞台画面一个专用的边色（白 18%），审片台同步。
- **向导底部对脚本线说了谎**：选了「脚本成片」，按钮已经变成「创建脚本成片」，
  底下还写着「预计耗时数分钟，消耗云端 API 额度」——这条线建出来直接进
  编导台，一次云端调用都没有。改成「建出来直接进工作台，不跑分析」。
- 找镜头面板：789 条的网格底部加渐隐；没有台词也没有画面描述的卡片，
  下面原来是一块纯空白，现在直说「没有台词，也还没有画面描述」。

### 第四批（真跑了一遍：配音 → 挑镜头 → 导出 → 剪映）

产品负责人放话「不怕花钱和删数据」之后，用 4 句台词的测试脚本把编导台
从头跑到尾。三个真问题都是跑起来才露出来的：

- **没内容也摆出「正在播」**：「自动铺一版」跑完无条件 `play()` 了一下。
  还没挑镜头时预览轨是空的——播放器进了「正在播」的状态却停在 0，
  屏幕上是一个暂停按钮配着 00:00 / 00:00，SnackBar 还说「铺好了，正在播」。
  状态跟事实对不上。现在先看方案空不空，空的就不播、也不那么说。
- **导出让人白填一遍表单**：脚本四句只挑了一句的镜头，点「导出成片」照样
  弹出规格面板；人选完分辨率、码率、编码、格式，点了「开始导出」，
  才蹦出「没能导出」。该拦的在进门口拦——现在先问 `blockingReason`，
  拦得住就直接说，不开面板。剪映那条同理（原来还要先等素材归集几十秒）。
- **同一个原因抄好几遍**（第三处、第四处）：导出拦截和剪映拦截都把
  「第 2 行还没挑镜头 / 第 3 行… / 第 4 行…」摞成三条。剪映更糟——它是
  遇到第一行就抛，人补完第 2 行再点，又说第 3 行。两处都改成按原因归堆、
  行号并区间，和编导台中栏用同一个函数。
- 顺带：导出对话框里补了一块「这一版里少了几句」，音色列表加渐隐。

**跑通的部分确认没问题**：可视化进度（「正在给第 2/4 句配音」+ 当前这句
+ 「完成后草片会直接播出来」）、左栏行状态点变绿、分镜卡上的字幕预览、
预览下方常驻的混音与字幕工具条、挑镜头后自动重铺并开播——这一段是
CLAUDE.md 里「可视化验的是它的判断逻辑对不对」的样子，没有要改的。

### 第五批（替换裂变端到端：审核 → 导出 → 验片）

- **三个地方各说各的**：底部状态栏说「当前组合 2 条」、导出对话框说
  「共 0 条成片」、而「进入矩阵导出」按钮照样可以点。根子是「排不出来」
  只有对话框知道——一条成片里不允许同一条素材出现两次，两个位置都只挑了
  同一条时每种排法都被丢掉。现在 `unavoidableClashes` 是纯函数：
  状态栏如实说、入口按钮禁用、原因点名到「素材 116719 同时用在
  U1·S7、U3·S1」。
- **导出进度只在「条」这个粒度跳**：合成一条 75 秒的片子二十几秒，
  屏幕上「0/2 · 第 1 条」纹丝不动。ffmpeg 的逐帧进度要改子进程执行器
  才拿得到（那会波及所有实现和测试假实现），而「这条已经跑了多久、
  上一条跑了多久」零成本就能说——现在是「0/2 · 第 1 条 · 已用 12 秒」。
- 「同一个原因抄好几遍」这个毛病一共修了五处，最后收敛成一个共享函数
  （`numberRanges` / `lineNumberRanges` / `unitRanges`）：编导台中栏、
  导出拦截、剪映拦截、审片台「还没选素材」的单元名。

**端到端验过了**：审核页剔掉撞车那条 → 状态栏和按钮当场恢复 → 真导出
2 条 → `ffprobe` 核规格（1080×1920 / 30fps / H.264 / 75.3s）→ 抽帧比对，
两条在 17.5s 处画面确实不同（U2·S2 换了不同素材），而烧上去的字幕
位置字号完全一致。

## 三、还没做

- 编导台里只剩「上传参考片提取台词」和「自动配镜」（要有参考片才跑得起来）
  没走查——那需要先传一条真参考视频。
- 审片台的「剪映」出口（替换裂变那条线）没真跑：它的拦截已经是前置的
  （`exportBlockedReason`），共享的规格面板也验过了。
- 编导台的字幕样式是**预览下方常驻的工具条**，审片台是浮层。这不是疏忽：
  审片台三栏区只有 385px 高（时间线要 370px 装六条轨），再塞一条工具条
  画面就只剩两百出头。浮层是那边条件下的解。
- 超宽屏（≥2560）仍有较多留白。竖屏素材在宽屏上留余量是固有的；
  真要吃掉它得让右栏进双栏（属性 + 候选同时在），那是另一个量级的改动。
- 过渡动效的系统性打磨。
- macOS 菜单栏（`PlatformMenuBar`）：主要命令现在只在界面里，
  不在系统菜单里，快捷键也就无从「被看见」。
