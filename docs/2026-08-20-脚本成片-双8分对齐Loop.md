# 脚本成片——「双 8 分」对齐 Loop

> 目标（用户定的硬指标）：**功能/工程视角平均 ≥8 分，产品（乔布斯）视角
> 平均 ≥8 分**，两个都到才算完。起点：5.4 / 3.2（见同日打分文档）。
> 方式：不贪一轮做完，一轮咬一口，每轮都比上一轮好一点，循环到双 8。

## 每一轮的固定流程

1. **验收**：真机跑全流程 + 截图，分别以两个视角评审
   （对照需求文档、即剪参考、上一轮的分数）
2. **开单**：列出本轮修改清单——**有限、聚焦**，只挑当前把分数
   压得最低的那几件
3. **设计**：动手前先想清楚形态（必要时写推演）
4. **实现 + 自验**：做完自己真机走一遍、截图核对
5. **复评**：两个视角重新打分，记录进本文档的轮次表
6. 未到双 8 → 回到 1

## 评分口径（两轮打分定下的，不再改）

- 功能/工程：核心旅程效率 25% / 自动化预填 20% / 可靠性透明 15% /
  视觉工艺 15% / 交互细节 10% / 连贯性 10% / 首次体验 5%
- 产品（乔布斯六问）：第一眼与欲望 / 焦点 / 简单 / 说人话 /
  魔法时刻 / 像素级工艺（等权平均）
