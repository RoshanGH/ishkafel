# 脚本成片——「双 8 分」对齐 Loop

> 目标（用户定的硬指标）：**功能/工程视角平均 ≥8 分，产品（乔布斯）视角
> 平均 ≥8 分**，两个都到才算完。起点：5.4 / 3.2（见同日打分文档）。
> 方式：不贪一轮做完，一轮咬一口，每轮都比上一轮好一点，循环到双 8。

## 每一轮的固定流程

1. **验收**：真机跑全流程 + 截图，分别以两个视角评审
   （对照需求文档、即剪参考、上一轮的分数）
2. **开单**：列出本轮修改清单——**有限、聚焦**，只挑当前把分数
   压得最低的那几件
3. **设计**：动手前先想清楚形态（必要时写推演）
4. **实现 + 自验**：做完自己真机走一遍、截图核对
5. **复评**：两个视角重新打分，记录进本文档的轮次表
6. 未到双 8 → 回到 1

## 评分口径（两轮打分定下的，不再改）

- 功能/工程：核心旅程效率 25% / 自动化预填 20% / 可靠性透明 15% /
  视觉工艺 15% / 交互细节 10% / 连贯性 10% / 首次体验 5%
- 产品（乔布斯六问）：第一眼与欲望 / 焦点 / 简单 / 说人话 /
  魔法时刻 / 像素级工艺（等权平均）

### Round 1 复评依据（真机 27 句滴露任务）

- 功能 6.9：旅程效率 4→7（上百次点击变两次）、自动化 5→8（配音/配镜/
  分时长/放慢充满全自动）、可靠性 8→8.5（进度舞台+失败点名）、
  视觉 5（没动）、交互 3→4（多了放慢充满，撤销/快捷键/拖拽仍缺）、
  连贯 7→7.5（完成自动开播）、首次 7→8（提取后顺路问）
- 产品 4.9：第一眼 3.5（视觉没动）、焦点 2→4（生成时中央是主角，
  平时预览仍不跟随行块）、简单 4→6.5、说人话 4→6（新文案全人话，
  存量系统语言仍在）、魔法时刻 2→5.5（草片自动诞生+开播，但零动效
  烘托）、工艺 4（没动）
- 距双 8 最大的洞：**视觉系统与像素工艺**（两视角都压分）、
  预览跟随/可 seek、存量文案、撤销与快捷键

### Round 2 开单（用户 08-20 真机反馈直接给的）

1. **行标签要能改**：不只点选/删除——从 miaoa 标签体系里搜索、

2. **找镜头检索维度重做**：台词 / 首帧截图 / 画面描述三维度可切，
   标签+项目是所有维度的统一外部约束；检索依据用参考视频的
   标签、首帧图、ASR 台词

## 北极星（每轮开单前先对着它问）

带字幕的草片——人从此只做否决和替换。
