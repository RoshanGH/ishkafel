> 逐功能的完整清单，每条标注 Windows 版**必须一样**还是**允许不同**。
> 对应 macOS 版 **0.1.226**。
>
> **「为什么这么设计」在原文档里**：`docs/2026-09-11-功能清单.md`（462 行）。
> 那份写于 0.1.223，**已有若干条过期**，本文在相应位置标出订正。
> 遇到取舍拿不准时回去读它的「设计初衷」段——那里记着每一次真机上踩的坑。

---

## 怎么读这份清单

每条三个字段：

- **能干什么** —— 功能本身
- **对齐** —— `必须一样` / `允许不同` / `必须一样（实现可不同）`
- **Windows 注意** —— 只在有坑时出现

三档的判据（完整推理见 `06-移植建议.md` 第二节）：

| 档 | 含义 |
|---|---|
| **必须一样** | 产品本身的样子。行为、数值、文案、视觉都要对齐 |
| **必须一样（实现可不同）** | 用户看到的结果要一样，底下怎么做随便 |
| **允许不同** | 这是「操作系统的部分」，应当入乡随俗 |

**凡是影响最终成片（导出的 mp4 / 剪映草稿）的，一律「必须一样」，没有例外。**

# 一、进门：新建任务与素材库

### 1.1 ★ 两条线的入口 —— `必须一样`

**能干什么**：新建任务时先选生产线——**替换裂变**（要原片的声音）或
**脚本成片**（不要原片的声音）。判据只有一条：*原片那个人的声音还要不要*。

截图：`ui-baseline/07-新建任务向导-步骤1.png`

### 1.2 新建任务向导 —— `必须一样`

**能干什么**：四件事一次填完——素材来源、**两层标签组**（台词语义单元组 +
视觉镜头组）、两层打标约束（人写的提示词）、限定在哪个 miaoa 项目下找素材。

> **订正（原清单 §1.2 不准确）**：素材来源实际有**三个**，不是两个：
> - `本地文件`（点击选择 mp4 / mov 成片）
> - `miaoa 成片库` —— **本期未开放**，界面明写「需要 miaoa 成片下载通道，
>   请先下载到本地」。原清单把「miaoa 视频 ID」列为可用来源，与实际不符
> - `不用原片，从素材拼`（空白任务 / 拼片）—— 原清单完全没提，
>   有独立设计文档 `docs/superpowers/specs/2026-08-12-blank-task-design.md`
>   和独立代码 `lib/features/blank_task/`

截图：`ui-baseline/08-新建任务向导-替换裂变.png`、`09-新建任务向导-脚本成片.png`

**Windows 注意**：文件选择器走 `file_selector`，Windows 实现已注册。
但 macOS 用 UTI、Windows 用扩展名过滤字符串，**扩展名大小写与「所有文件」
选项的行为不同**，要实测。

### 1.3 miaoa 素材库对接 —— `必须一样（实现可不同）`

**能干什么**：登录（手机号验证码）、拉取企业与项目、拉取标签库、按三种方式
检索候选素材、把选中的素材下载到本地。

**Windows 注意**：⚠️ **这是最大的外部未知数。** 现在全部走 miaoa CLI 子进程
（`lib/core/miaoa/miaoa_gateway.dart` 是唯一出入口，有架构测试守着）。
Windows 上需要 miaoa 提供二进制；没有的话只能改走 REST API 直连。
`lib/core/diagnostics/tool_installer.dart:244` 已经有 "unsupported platform"
的处理分支，可以从那儿接。

# 二、分析：把一条片子拆成可操作的结构

### 2.1 ★ 两层切分 —— `必须一样`

**能干什么**：导入后自动跑完——提取音频 → 人声/背景分离 → ASR（句级+字级
时间戳）→ 镜头切点检测 → LLM 语义分组切出**台词语义单元** → 在每个单元内部
切出**视觉镜头** → 两层各自打标。

三条不可动的规则：
- **按台词语义切，不按画面切换切**
- **严格嵌套**：视觉镜头不可跨单元，单元边界必然同时是镜头边界
- **切点不信 ASR**：ASR 时间戳只做粗定位（±0.5s），LLM 分完组后在 ±0.6s 窗口内
  吸附到**本地帧级信号**（优先视觉镜头边界，次选静音谷）

**Windows 注意**：`lib/core/analysis/frame_signal_extractor.dart:69` 把文件路径
塞进了 ffmpeg 的 filtergraph：
`metadata=print:file=$outPath`。**Windows 路径里的 `C:` 冒号是 filter 的选项
分隔符、反斜杠是转义符 → 这条命令必然解析失败。** 见 `05` P0。

### 2.2 分析结果按内容指纹缓存 —— `必须一样`

**能干什么**：同一条片子重新导入，直接复用上次的切分。
按 `sourcePrint`（源文件内容指纹）缓存，不是按文件名。

### 2.3 断点续跑与后台补齐 —— `必须一样`

**能干什么**：切分一出来就能进工作台（22.5 秒），**打标在后台继续补**。
分析失败有原因和重试入口；打标中断下次进来接着跑。

# 三、审片台（替换裂变）

截图：`ui-baseline/11-审片台.png` 是这个页面的基准图。

### 3.1 ★ 双层时间线 —— `必须一样`

**能干什么**：六条轨——台词语义单元、视觉镜头、字幕、配乐、画面缩略图、音频
波形。缩放、平移、跟随播放头；点选任意一块，右侧属性面板跟着变。

**精确尺寸全部在 `04-UI视觉规范.md` 第 3.4 节**，由
`test/features/workbench/timeline/timeline_tracks_layout_test.dart` 钉住：
六条轨含标题条共 **330px**，工具条 **40px**，时间线区占 body 的 **35%~55%**。

三条硬规则：
- **时间线是主操作区**，占比要足
- **所有时间数字一律成片时间**
- **帧对齐是强制的**：所有切分边界以帧为最小单位，时间码精确到帧
  （`00:17.28` = 17 秒第 28 帧，**不是 17.28 秒**），卡片上带图例

**Windows 注意**：
- 鼠标滚轮缩放已兼容 `isControlPressed`（`timeline_view.dart:1003`），
  但 **macOS 触控板是像素级连续滚动，Windows 鼠标滚轮是 120 单位离散跳跃** →
  缩放会一格一格跳，需要调 scale 系数
- 时间线贴左边缘，页面转场已全平台强制 `FadeUpwards`
  （`app_theme.dart:45-48`）避免边缘拖拽返回吃掉横向拖选，这条**不要改**

### 3.2 ★ 替换模式 —— `必须一样`

> ⚠️ **原清单 §3.2 的「三种模式互斥」那张表已经过期。**
> 0.1.226 引入「底片」概念后，整体替换与镜头替换**不在同一层**：

| 概念 | 定什么 |
|---|---|
| **底片**（`UnitBase`） | 这一段画面从哪张片子的哪一段来 |
| **整体替换** | 定**底片是谁** |
| **镜头替换** | 定在这张底片上**换掉哪一刀** |
| **保留原片** | 底片就是原片，不换 |

数据上：`ReplacementMode { keepOriginal, whole, perShot }` 仍是三态枚举
（`lib/core/replacement/replacement_plan.dart`），但单元身上多了
`baseCandidateId`，它同时是「底片已固定」的标记。

底片的几条规则（全部 `必须一样`）：

| 规则 | 内容 |
|---|---|
| **底片多选 ⟺ 没精修** | 底片能多选（= 出 N 条变体），**只要不切分**。一旦切分，收敛成单条 |
| **换底片：允许，但点名** | 弹确认框写明「这一段已挑的 N 处镜头替换会全部清掉」 |
| **切分打标：显式触发** | 不在选完素材时偷偷跑——要花钱、要等 |
| **递归到此为止** | 一层底片 + 一层镜头，不再往下切 |
| **底片不变速，替换进来的才变速** | 底片定了这一段多长 |
| **底片是素材时不渲台词字幕** | 时长跟素材走、和原坑位对不齐，按原时间戳贴必然错位。界面显式标一句 |

镜头坐标换算只有**一个式子**，预览、导出、抽帧、剪声音全用它：
```
base.startMs + (shot.startMs - unit.startMs)
```

### 3.3 ★ 候选检索三模式 —— `必须一样`

**能干什么**：三种互斥的找素材方式，两层通用——**标签精确筛** / **画面描述
语义搜** / **首帧以图搜图**。候选可多选，带时长差徽标（绿=变速容忍内，
橙=超限）、低清徽标、烧字警告、品牌角标。

截图：`ui-baseline/15-审片台-候选素材-结果.png`（徽标全在图上）

原清单 §3.3 没提到的子能力（都 `必须一样`）：
- **项目排除**（`lib/features/picking/project_exclusion.dart`）
- **标签命中探测与查询收窄**（`tag_hit_probe.dart` / `tag_query_narrowing.dart` /
  `tag_result_usability.dart`）—— §6.3 里那句「标签命中 5318 条太宽」的播报
  就是这里产生的
- **已挑素材托盘**（`picked_tray.dart`）
- **候选排序**（`candidate_ranking.dart`）

### 3.4 ★ 画面复核 —— `必须一样`

**能干什么**：对候选素材首帧做一次 Vision 调用，一次问清两件事：
**画面上烧着什么字**、**露出的产品是谁家的**。

两条不可动的语义：
- `burnedText` 的 **null = 还没看过，空列表 = 看过且干净**，绝不能混
- **「认不出来」给 null**，瞎猜一个牌子比承认不知道更糟

**品牌一致性尤其要紧**：替换裂变里跨品牌露出会直接出事故。
`Shot.productBrand` 是「本片是什么品牌」的唯一可靠来源。

### 3.5 属性面板 —— `必须一样`

**能干什么**：跟随选中对象三态显示（单元 / 镜头 / 无选中）。

截图：`ui-baseline/12-审片台-单元属性.png`（上半）、
`21-审片台-属性面板下半.png`（下半：打标过程、配音、单元台词）

- 单元上：改台词、**逐帧微调边界**、拆分、并入、手填标签、换音色
- 镜头上：改边界、改标签、改这一镜的字幕、设两层声音

> **补充（原清单 §3.5 没写）**：0.1.226 新增**「这一段的底片」卡片**
> （`lib/features/workbench/base_segment_card.dart`）。只对「底片是素材」的
> 段落出现，按钮：**切分这一段 / 重新切分 / 换一张底片**，外加
> **「给这些镜头打标」**按钮（新切的镜头没打标时卡片会说出来，不自动跑）。

**设计规则**：**逐帧步进按钮而不是拖边界**——在轴上把两段拉来拉去只带来误操作。

### 3.6 ★ 多轨预览 —— `必须一样（实现可不同）`

**能干什么**：画面轨、口播轨、素材原声轨、配乐轨同时播，按成片时间轴对位。
换方案不重新合成。

**核心约束**：**预览的全部意义就是「听到的就是要交付的」**。预览与导出
**共用同一个混音器**（`AudioTrackBuilder`）和同一套缓存——
**不要为预览另写一条路**。

预览必要时可以降级（比如分离轨还没好先放原混音），**但必须把降级说出来**。

**Windows 注意**：media_kit 在 Windows 上用 ANGLE，
**硬件解码路径和 seek 精度需实测**——这个产品对逐帧 seek 有强依赖。

### 3.7 字幕层 —— `必须一样`

**能干什么**：换过素材的镜头会重新烧字幕。字幕在预览里是**画面上现画的一层**
（不烧进文件），拖位置、改字号、换颜色、换衬底即刻可见；字幕文字和时间都能改。

截图：`ui-baseline/16-字幕样式浮层.png`

三条设计规则：
- **为什么现画不烧录**：烧进切片的话每动一下滑杆都要重渲 → 播放器重开文件，
  转圈几秒、位置归零
- **为什么只有换过素材的镜头才有字幕**：没换的镜头台词字幕烧在原片像素里
- **为什么能手改**：默认按 ASR 的词级时间戳切给各镜，而「哪里断句好看」
  是编导的判断

> **补充**：0.1.224 起字幕时间用**成片时间码**（`00:23.00`，`.10` 是帧号
> 不是小数），`parseTimecode()` 认多种写法、帧号超出这一秒时夹到满帧
> **不进位**、认不出返回 null **不猜**。**存的仍是相对这一镜的毫秒**，
> 挪单元时时间码自动重算。时间线拖字幕 `alignToFrame` 吸帧。

> **⚠️ 字幕样式浮层必须是非模态的。** 0.1.218 特意从蒙灰对话框改成浮层——
> 照着画面判断的面板一律不许压暗背景、不许拦点击，压暗和拦点击都会毁掉
> 判断依据。截图里可以看到背景完全没变暗。

### 3.8 ★ 两层声音 —— `必须一样`

**能干什么**：被替换的那一镜，声音是两层，各自四档（不播放 / 人声 / 背景声 /
原声）+ 独立音量。全片打底 + 单镜覆盖两级。

四条刻意的取舍，**一条都不能改**：
- **没点过 = 自动**（原混音；铺了配乐就换纯人声）
- **一旦点了任意一档，就完全按他选的来**——冲突只提示，不替他改
- **各层相加，不取平均**。叠出来真过载了**点名是哪一段**，不偷偷压
- 「不播放」垫的是**等长静音**，不是少拼一段

> **文案补充**：固定了底片的段落上，「原片这一镜的声音」叫
> **「底片这一镜的声音」**。

### 3.9 换音色（TTS）—— `必须一样`

**能干什么**：按单元换音色，生成配音替换原口播。音色库、试听、本片基调 +
单行覆盖，语速可调，配音生成后落库复用。

**换音色与整体替换互斥**，导出前置检查拦下并说明，不静默取其一。

### 3.10 配乐 —— `必须一样`

**能干什么**：横向拖选一段连续的台词语义单元铺配乐，每段独立音量，
**一段可选多首互为备选**。曲库来自 miaoa，本地缓存。

> **精确口径（原清单没写，0.1.225 才写死）**：
> - 配乐**不参与笛卡尔积**，按 `variantIndex % materials.length` 轮流用
> - 导 N 条、M 首就各 N/M 条，除不尽一个多一个少
>   （由 `bgm_even_split_test` 钉住）
> - 预览只放标 ★ 的那首；★ 那首被删后**退回第一首**（不是 clamp 到最后一首）
> - 选曲面板行首是**方框**（多选形状），只在「替换分镜」那类只准挑一首的
>   场合才用圆形

**按台词语义单元对齐，不按镜头**——整体替换之后单元还在，镜头没了。

被配乐盖住的段落自动改用**分离出来的纯人声**。

### 3.11 审核候选 —— `必须一样`

**能干什么**：把这一批挑中的素材摊在一页上逐条过，悬停即播，剔掉不合适的。

截图：`ui-baseline/18-审核候选.png`

剔除结果**直接落进替换方案**（唯一真相），不是另存一份回执。

### 3.12 编辑后果对话框 —— `必须一样`（原清单完全没提）

**能干什么**：改完切分结构（拆分/合并）后弹出「改完之后要连带处理吗？」，
列出受影响单元和改动幅度百分比，三个选项：
- 清除这几个单元已选的替换素材
- 标记为待重打并立即送去打标
- 跳过

文件：`lib/features/workbench/edit_consequence_dialog.dart`

### 3.13 打标过程可追溯 —— `必须一样`（原清单没提）

**能干什么**：「查看打标过程 / 收起打标过程」折叠区——采样了哪几帧（时刻列表）、
用了哪几个词表组、词表多少个词、耗时、**模型原样回复**、打标时间、
以及**标签过期徽标**。

文件：`lib/features/workbench/tag_trace_section.dart`
截图：`ui-baseline/21-审片台-属性面板下半.png`（顶部可见入口）

这是「可视化模式」精神在打标上的落地。

### 3.14 任务标签组事后可改 —— `必须一样`（原清单没提）

**能干什么**：进了工作台还能改标签组，带「保存后立即用新词表重新打标」复选框。

截图：`ui-baseline/17-标签组对话框.png`
文件：`lib/features/workbench/task_tag_groups_dialog.dart`

# 四、编导台（脚本成片）

截图：`ui-baseline/24-编导台-行带式工作台.png` 是基准图。

### 4.1 ★ 行带式工作台 —— `必须一样`

**能干什么**：一行台词一个带子，逐行写台词 → 生成配音 → 配画面 → 铺配乐。

三栏：**左 = 脚本（唯一的真相 + 总览导航，360 定宽）；中 = 预览（成片的影子，
400 定宽）；右 = 当前行的工作台（Expanded）**。

**根是台词**——「脚本即成片」。节奏由配音决定，所以**配音先于画面**：
先知道这句话念多久，才知道要配多长的画面。

行的类型（`voiced` / `visual`）是**由 text 是否为空派生的，不是用户选的**：
回车即新行，空行即画面行。

截图 `ui-baseline/23-编导台-起步引导.png` 是空脚本时的引导页。

### 4.2 参考片复刻 —— `必须一样`

**能干什么**：上传一条参考片，提取它的台词、逐行的参考镜头（首帧）、
镜头时长分配，然后照着这个结构去找自己的素材。

参考镜头给 Agent 的是**看图判断的依据**。

### 4.3 逐行配画面与时长分配 —— `必须一样`

**能干什么**：一行可以配多个镜头，自动/手动分配每镜占多长；镜头不够铺满
这一行时会点名说清楚。

# 五、出片与交付

### 5.1 ★ 矩阵导出 —— `必须一样`

**能干什么**：把各位置选中的候选做组合，一次批量合成，**上限 100 条**。
导出前摆出「这几条各用什么」（位置标到 `U2·S2`），导出后列出实际文件名。

截图：`ui-baseline/19-矩阵导出.png`

### 5.2 ★「挑差异最大的」—— `必须一样`

**能干什么**：从全部组合里挑 3/5/10/20 条彼此差异最大的。

**规则**：**每个位置的候选按配额摊开**（5 个候选出 10 条 = 各 2 次），
配额之内才比距离，收尾做一轮局部交换把偏斜换平。

> 人既然挑了 5 条，5 条就都得露面。「看着像」不是重复用同一条的理由。

### 5.3 导出规格与帧率 —— `必须一样`

**能干什么**：分辨率（480/720/1080/1440/2160）/ 帧率（24/25/30/50/60）/
码率 / 编码（h264/hevc）/ 格式（mp4/mov）可选，预计大小实时算。

**帧率默认跟着原片走**（取不高于原片且最接近的档）；手动选到比原片低时
会说清楚在丢帧。

**Windows 注意**：编码一律软编 libx264，**两边完全一致**。
不要在 Windows 上默认启用 NVENC/QSV——那会让两边成片不一致。
（作为可选项提供是另一回事，但不能是默认。）

### 5.4 ★ 出门前的交付拦截 —— `必须一样`

**能干什么**：导出**在进门口**拦下会静默出错的几种情况并点名：
- 整体替换与换音色冲突
- 选了音色没生成配音
- 有配乐却没有人声轨
- 选了要分离的声音档位却没有分离轨
- 手加的单元还没挑素材
- 同一条素材占了两个位置导致一条都排不出来
- **素材画面上本来就烧着字，成片会出现两层字幕**

截图：`ui-baseline/19-矩阵导出.png`（橙色警告区）、
`ui-baseline/29-编导台-导出拦截.png`（「还导不了」）

**该拦的在进门口拦。** 这些错的共同点是——**导出来的片子看着正常，
其实不是用户要的**，他发现不了，所以宁可不导。

### 5.5 同名不覆盖 —— `必须一样`

**能干什么**：往同一个目录导第二批时，撞名的文件往后排（`变体1(2).mp4`）。

**Windows 注意**：`lib/features/workbench/workbench_page.dart:2665` 的
`_safeName` 只过滤 `[/:\\]`，**漏了 Windows 的 `* ? " < > |`**，也没处理
`CON/PRN/AUX/NUL` 保留名和结尾的 `.`/空格。
`lib/core/jianying/jianying_writer.dart:166` 过滤得完整，**拿它当参考实现**。

### 5.6 ★ 剪映草稿交付 —— `必须一样（实现必然不同）`

**能干什么**：生成剪映草稿工程——分子轨、原子轨、候选轨、口播轨、配乐轨、
字幕，素材一并落地。

人已经做的精修。

**Windows 注意**：⚠️ **这一块在 Windows 上要整体重测**：

# 九、贯穿全局的几条规矩 —— `必须一样`，一条都不能松

| 规矩 | 为什么 |
|---|---|
| **不静默降级** | 影响成片的东西出错就失败并点名。可降级的只有预览这类「人还在看着」的环节，且必须说出来 |
| **缓存按内容指纹** | 按文件名存在就当命中，会静默放出上一个版本的内容。**改了规则就要改指纹** |
| **不留孤儿数据** | 每一份数据都要有人读、有人删 |
| **状态可见可操作** | 后台在干活就说清在干什么、到第几步；失败给原因和重试入口 |
| **存了就要报** | 存进去却不在 `--json` 里报出来，Agent 查到的空看起来正好像「没问题」 |
| **同一件事只有一处说了算** | 两处各算各的，迟早不一样。这个项目在这上面栽过不止三次 |

| 等宽字体 | `Menlo`（6 处） | `Consolas` / `Cascadia Mono`。**建议抽 `AppFont.mono` token** |
| 滚动条 | macOS 覆盖式、自动隐藏 | Windows 默认占位会**挤掉布局宽度**。建议统一成覆盖式（`ScrollbarTheme`），否则三栏宽度要重新目测 |
| 滚轮缩放手感 | 触控板像素级连续 | 鼠标滚轮 120 单位离散，**需要调 scale 系数** |
| 安装与分发形态 | `.app` + zip + Developer ID 签名 | `.exe` / MSIX / Inno Setup + signtool |
| 提权 | `osascript ... with administrator privileges` | **建议不提权**，装到 `%LOCALAPPDATA%` |
| 隐私授权 | macOS TCC（读文稿弹框、自动化权限） | **Windows 无 TCC，这一整类问题消失**。但 Defender SmartScreen 会拦未签名 exe |
| 日志出口 | `stderr`（GUI 以 `open` 启动时不可见） | ⚠️ Windows GUI 进程默认没有控制台，**stderr 直接进黑洞，打包版所有日志丢失**。**建议加文件日志** |
