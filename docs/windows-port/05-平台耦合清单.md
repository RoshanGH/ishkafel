# 五、平台耦合清单

> **穷举**每一处 macOS 假设：`文件:行号` / 现状 / 在 Windows 上会怎么坏。
> 宁可多列不要漏——漏掉一条，那边就会踩一次坑。
>
> 前提事实：
> - **全仓 0 处 `Platform.isMacOS`**。唯一的平台分支是 `bin/ishkafel.dart:418`
>   的 `if (!Platform.isWindows) sigterm.watch()`（这条已正确处理 ✅）
> - `windows/` 目录只有 2 次 commit（`3b38f84` 初始化、`87965d7` media_kit 接入），
>   **全是 `flutter create` 模板，零自定义代码**
> - `windows/flutter/generated_plugin_registrant.cc` 只注册了
>   `file_selector_windows` / `media_kit_libs_windows_video` / `media_kit_video`，
>   而 macOS 侧还有 `package_info_plus` / `wakelock_plus`
>   —— 说明 **windows 侧从没真正 build 过**。**第一件事就是跑一次
>   `flutter build windows` 看能不能过。**

### ⚠️ 路径里的 `:` 还有第二处雷 —— P0

**`core/analysis/frame_signal_extractor.dart:69`**
```dart
'-vf', "select='gt(scene,0)',metadata=print:file=$outPath"
```
**把文件路径塞进 ffmpeg 的 filtergraph。**
Windows 路径 `C:` 里的冒号是 filter 选项分隔符，反斜杠是转义符
→ **这条命令在 Windows 上 100% 解析失败。**
必须转义成 `C\:/path` 形式，或改用相对路径 + `cwd`。

### ⚠️ 文件名非法字符

- **`features/workbench/workbench_page.dart:2665-2666`** `_safeName` 只过滤
  `[/:\\]`，**漏了 Windows 的 `* ? " < > |`**，也没处理 `CON/PRN/AUX/NUL`
  保留名和结尾的 `.`/空格。**任务名进路径会炸。**
- ✅ `core/jianying/jianying_writer.dart:166` 过滤得完整（`[/\\:*?"<>|]`）
  —— **拿它当参考实现，把 2665 那条对齐过来。**
