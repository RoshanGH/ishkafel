# 脚本成片（编导台）——设计讨论记录

> 状态：设计已定稿（2026-08-19）
> 日期：2026-08-19
> 参与：用户（产品决策）+ Claude（整理与追问）
> 术语沿用 [术语表](./术语表.md)

## 一、定位（已对齐）

新建任务的**第四种成片来源**。核心转变：**生产的第一公民从「原片」变成「脚本」**。

现有成片翻新是「结构锁死、只换画面」；本模块反过来——编导写的脚本就是片子
的骨架，镜头、配音、时长、字幕全部从脚本生长出来。目标是把编导现在用的
脚本表格（配音文案 / 大字报 / 画面描述 / 参考分镜路径 各列）变成**可执行的**：
编导写完脚本，生产即完成，不再交给剪辑执行。

**复刻与原创统一在同一条流程**，枢纽是「脚本行」（一行 = 一个台词语义单元）：

- **原创**：编导手写脚本，一行一句；每行去 miaoa AI 搜配镜头
  （台词语义搜 / 画面描述搜 / 参考图首帧搜）
- **复刻**：上传参考视频 → ASR → **AI 按语义断句自动生成脚本行**——
  台词是它的文案，切出来的段落是它的参考镜头（自带三种搜索键：
  首帧图 / 台词 / 画面描述）→ 编导在此基础上改
- 之后同一条路：挑镜头（参考 + 候选对照，同审核页形态）→ 改台词 →
  克隆配音 → 镜头变速适配新时长 → BGM / 字幕 → 导出
  （远期：一键生成剪映草稿拉起剪映精修）

### 复用现有零件

ASR / 语义切分（复刻入口）、miaoa 三模式检索、审核式对照挑选、
TTS 克隆配音（换音色管线）、变速适配（SpeedFit）、BGM、字幕重渲、
ffmpeg 导出管线。

### 真正的新东西

1. 脚本行数据模型（不再以原片时间轴为根）
2. 三栏工作界面：左脚本 / 中预览 / 右每行的镜头模块
3. 「配音时长驱动时间轴」的编排逻辑
4. 剪映草稿导出（优先级待定，见问题③）
5. 上传声音样本克隆自定义音色

### 参考产品（即剪AI）的观察

文案在左、预览居中、右侧每句台词一段配匹配分镜（可替换/删除）；
支持导出成片或导入剪映草稿。**它的不足**（我们要超越的点）：
整个任务只能选一个音色——我们要按台词语义单元独立选音色。

## 二、已定决策

### 问题①：声音策略（2026-08-19 定）

1. **默认克隆配音**；配音是每个单元时间轴的**根**——配音没生成，该单元
   没有时间轴可供操作；镜头对齐一律以配音生成后的真实时长为基准
2. 改台词 / 换音色 → 重新克隆 → 时长变化 → **该单元内已做的镜头对齐
   作废重排**（设计内的正常代价；同一句台词不同音色时长可差近一倍）
3. **音色粒度 = 台词语义单元**，每个单元独立选，不做全任务单音色。
   同画面双人对话（男女声）通过拆成两个单元各选音色解决
4. 每个单元小模块上的两种声音方式（有参考视频时）：
   - **克隆参考片的声音**：音色 + 语气都从参考片该段复制
   - **只借语气、换音色**：保留参考段的情绪节奏，音色换成选定的
     （即现有换音色管线：ARK 分析参考段语气 → TTS）
5. **音色来源**：火山方舟音色库 + **上传一段声音克隆自定义音色**（新功能）

### 脚本行与右侧模块的对应（2026-08-19 定）

左边脚本多少行，右边就多少个镜头小模块，严格 1:1。
上传参考视频时脚本行由 AI 按 ASR 语义断句自动生成。

### 问题②：脚本行的类型（2026-08-19 定）

只有两种行：

1. **配音行**：有台词 → 克隆配音 → 配音时长是该单元时间轴的根
2. **画面行**（无台词行）：脚本这一行为空但结构上存在——有画面、可铺
   BGM；声音 = BGM 或所选镜头素材自带的原声；没有配音主体

**时长的根，按行类型分**（2026-08-19 定）：

- **配音行**：配音时长永远是根，素材向它对齐（变速/裁切），不可另填
- **画面行**：两种都支持，脚本区不承载时长（脚本就是脚本，只管结构）——
  - **手填秒数**：填了就是根，所选素材向它对齐（裁切/变速）
  - **不填**：时长 = 所选素材（变速后）的实际时长，直接取用

**大字报 / 画面花字：本软件不做。** 表格里的「大字报」行本质就是画面行
（字是贴在画面上的，不属于配音体系）；花字属于拉起剪映精修的范畴——
这给剪映草稿导出（问题③）加了权重：它是花字类需求的唯一出路。

### 问题③：剪映草稿导出（2026-08-19 定）

**一期只做自有导出**（复用现有 ffmpeg 管线），剪映草稿放二期。
二期机制方向：生成剪映的草稿文件（素材已全部在本地），让剪映打开
草稿——台词、画面、声音、BGM 按顺序排进轨道，人在剪映里精修
（花字/动效类需求的出路）。具体格式细节届时由用户提供参考方式。

### 问题④：脚本行内的镜头结构（2026-08-19 定）

一个脚本行（右侧一个模块）内**允许多个镜头**，模块里带参考镜头
（复刻时来自参考段切分）——保留「台词语义单元 ⊃ 视觉镜头」两层结构，
与现有模式同构。「一句文案配床单+马桶+枕头一套三个连续镜头」的场景
自然成立。具体呈现待 UI/UX 设计。

## 四、参考产品拆解（即剪AI，8 张截图存于 `参考内容/即剪/`）

### 布局与信息结构

- **三栏**：左 = 整篇脚本（含所用音色标注）｜中 = 预览 + 全局参数 +
  导出双按钮（导出成片 / 导入至剪映）+ 底部「音色 / 音乐 / 字幕」三 tab
  ｜右 = 分镜编辑流（每段一张卡片，点句子跳播、改完自动重播该句）
- **全局参数**：分辨率（9:16 / 3:4）、语速倍率（1.0–1.5x）、音色音量 /
  背景音乐 / 原声音量三路、视频缩放、字幕缩放、视频原声开关
- **右侧段卡片**：每句带时间戳 + 角色标签（钩子/卖点）；镜头卡显示
  素材名、匹配度（高/中/低）、时长与倍率（3.5s·0.77x）、已用区间
  （0.00–2.72s）、慢放/裁尾/复用徽标；替换 / 删除 / 「+」加镜头位

### 关键交互（用户标注的重点）

1. **「调整画面」弹窗**（段内多镜头时长分配）：配音时长是总约束；
   段内每镜一条胶片条——拖窗口选素材区间、拖右缘调本镜时长，
   **下一镜自动继位、总时长不变**；点左侧预览试播
2. **「替换」弹窗**：AI 候选按匹配度排 + 上传新视频 + 全部素材网格
   （「本句在用 / 他句在用」防撞车标注）。**我们在此接 miaoa 三模式搜索**
   （用户明确标注）
3. **改文案闭环**：文案就地编辑 → 重新克隆 → 音频时长变化 → 该段镜头
   时长重新适配（与本模块问题①决策一致）
4. **多句合并成段**：「第 1 段·合并镜·2 句（可拆开）」——两句台词共用
   一组镜头（待讨论 A）
5. 编导脚本表格还支持「抖音链接 + 截取时间段（支持多个视频）」作为
   参考素材来源

### 即剪的不足（我们要超越的）

- 全任务单音色（我们：按单元选）
- 素材检索无语义搜索（我们：miaoa 三模式 + 标签体系）
- 句子角色标签只是展示（我们：话术标签组是现成的受控词表，
  可反向当检索键）

## 五、产品设计主张（2026-08-19，待用户认可）

### 理念：脚本即成片

编导面对的永远只是他的脚本，片子是脚本的影子。心智模型是「我在写一个
会自己变成视频的文档」，不是「我在操作剪辑软件」。专业概念（变速/对齐/
匹配度/克隆）一律退到幕后，只在需要人判断的一刻浮现。

### 四条设计律

1. **改字即改片，永不手动「重新生成」**。改完台词失焦即自动重配音 →
   自动重适配镜头 → 自动重播该句。（即剪要用户自己点「重新克隆」，
   是它最大的败笔）
2. **每一行是有生命的细胞**。行状态：草稿(灰) → 配音中(呼吸黄) →
   镜头待补(橙) → 就绪(绿)。顶部整片就绪度「27 行 · 24 就绪」；
   **导出只在全绿时点亮**——「不静默降级」在本模块的形态
3. **默认全自动预填，人只做否决**。复刻入口产出的不是空架子，而是
   已配音、已预配镜头的完整草片（ASR 断句成行 + 台词语义预搜 miaoa
   填候选 + 参考镜头就位）。编导的工作从「生产」变成「审」——
   审片台基因的延续，与即剪「让人组装」的根本差别
4. **参数跟着对象走，不设全局参数墙**。语速/音色/原声开关是行的属性，
   BGM 音量是 BGM 段的属性；中栏不放滑块墙

### 三栏的职责重定义（与即剪的关键差异）

- **左栏 = 脚本（唯一的真相 + 总览导航）**：像文档一样写，回车即新行，
  空行即画面行。每行：文案 + 状态点 + 角色小标 + 音色微标
- **中栏 = 预览（成片的影子）**：竖屏播放器；播放头与左栏行双向联动。
  只有播放器 + 时长 + 导出
- **右栏 = 当前行的工作台（聚焦深工）**：配音卡（音色/试听/语气来源）+
  镜头序列（参考镜头居首、每镜时长胶片条、miaoa 三模式找镜头）。
  即剪右栏是全部段滚动列表（与总览职责重复）；我们总览归左栏、
  深工归右栏，职责不重叠

### 讨论点 A/B/C 的决定（待用户否决）

- **A 多句共用镜头组：做，但不引入「段」概念**——概念只有「行」，
  相邻行可「链」起来共用一组镜头（行首链接标记，镜头组挂链头）。
  即剪的段/句/镜三层砍成行/镜两层
- **B 角色标签：做**——打标管线现成，行首彩色小标（钩子/痛点/促单），
  自动成为该行找镜头的检索键之一。纯增益
- **C 素材原声垫底：行级开关，默认关**——不做全局三路混音滑块

## 六、一行的解剖——右栏工作台操作设计（2026-08-19，待用户逐条过）

选中左栏任意一行，右栏三张卡：

### ① 配音卡

- 台词就地编辑（与左栏同一份数据）。**配音显式生成**（2026-08-19 修订，
  推翻「失焦即重配」）：改台词后行状态变「台词已改，配音未更新」（黄），
  旧配音仍可听；行上出现「生成配音」按钮，编导改满意了点一下才调 API
  ——钱只花在确认过的版本上。生成完自动重适配镜头、自动重播
- 音色：头像微标点开音色面板（库 + 我的克隆音色，可试听），
  永远显示本行当前用谁
- 语气来源（仅复刻行）：克隆原声 / 只借语气换音色；原创行不出现
- 语速：行级倍率 0.9–1.5x（默认 1.0），改语速=改时长=镜头自动重适配
- 素材原声：行级开关，默认关
- 试听：单独播本行配音，生成中呼吸态

### ② 镜头序列卡

- **参考镜头模块常驻**（2026-08-19 修订：不分复刻/原创）——复刻行
  自动带参考段，原创行可手动上传参考视频；参考的 ASR/首帧/画面描述
  即成为本行搜索键。审核页「原片卡」同款样式，悬停即播，不进成片
- **参考镜头保持双层结构**（自相似）：整片参考→切成行；行参考→切成
  镜。上传 10s 参考自动跑视觉切分，切出 N 个参考分镜 = 本行 N 个
  镜头位，每位以参考分镜打底、按首帧+描述自动预搜候选。镜头位可删，
  删后剩余镜头摊时长
- **「按参考重新配镜”按钮**：改乱了想恢复时点它，弹确认「将覆盖本行
  已选的 N 个镜头」——破坏性覆盖显式、单行范围
- 已选镜头横排：缩略图 + 时长·倍率 + 已用区间，悬停即播
- **时长分配内嵌不弹窗**：镜头卡下缘迷你胶片条，拖右缘调本镜时长、
  邻镜自动继位（总时长 = 配音时长锁死）；点开镜头卡才展开大胶片条
  精调素材取用区间。高频操作留在原地，低频操作才展开
- 镜头拖动重排；删除即时、时长由剩余镜头自动摊
- 「+」加镜头 = 展开找镜头面板

### ③ 找镜头面板

- 默认躺着 AI 候选（按台词预搜、匹配度排）——人从候选里挑，不从零搜
- **标签是所有检索的公共筛选层**（2026-08-19 修订，非并列第四入口）：
  面板顶部一条标签栏，预填本行/本镜已打的标签（可当场增删改），
  下方无论 AI 候选 / 画面描述搜 / 以图搜（有参考默认用首帧一键搜）
  **都在这组标签筛选之下执行**。实现注记：miaoa 接口若不支持语义+标签
  联合下发，则拉回后按候选自带标签本地过滤，效果等价
- 候选标注「本行在用 / 他行在用」（沿用现有防撞车拦截）
- 上传本地视频入口压尾（兜底非主路径）

### 行级操作（发生在左栏）

- 回车新行、退格删空行、行拖动排序
- 行首链标记：与上一行链住共用镜头组
- 角色标签自动打、点击可手改
- 点行 = 中栏跳播该行

### 行内镜头时长分配（2026-08-19 定稿）

每个镜头位的本质：**从素材里截一段（可变速）**。

- **时间账**：各镜「选用时长」之和 = 配音总时长，硬约束、实时显示
- **每镜三个自由度**：
  1. 变速倍率：显式选择（预设 0.5/0.75/1/1.5/2x + 自定义，默认 1x）。
     变速改变素材**可用总量**（6s 素材 2x → 可用 3s）
  2. 区间起点：在变速后的时间轴上拖窗口框选，不必从头
  3. 选用时长：框选窗口宽度，即该镜进成片的长度
- **联动规则**：
  - 触发变速 → 该镜已框区间**清掉重框**（不做智能换算，清掉最诚实）
  - 拖某镜窗口变宽 → 邻镜自动变窄（总长锁死）
  - **每镜最小 0.5s**：拖到阈值不让继续，提示「再短就删掉这一镜」；
    删镜是显式动作
  - 素材可用量 < 需要的选用时长 → 该镜标警告（换素材/减时长/改倍率）
- **初始默认**：配音时长均分、区间从素材头起、1x 不变速

### 标签体系与现有模块同构（2026-08-19 补）

- 建任务先选标签组（受控词表），与现有模式一致
- 两层打标照旧：行（分子）按台词打、参考分镜（原子）按画面打——
  有参考视频自动打，手写脚本对台词打；标签挂在行/镜上，可改可删
- 打好的标签自动成为该行/镜检索时的预填筛选条件（见找镜头面板）

## 七、导出 / BGM / 字幕（2026-08-19 定）

### 导出

一次一条成片（行内多镜头是**序列**，都按顺序进片，不是候选池）。
矩阵变体不属于本模块一期。

### BGM

- 现有引擎原样复用：跨行区间铺设、相邻段同曲**连续播放不重头**
  （数据结构与 BgmSegment 同构，「单元区间」换成「行区间」）
- **选择入口在脚本侧**：左栏拖选相邻多行 → 「铺配乐」→ 选曲；
  行侧竖向色带标出范围，点色带换曲/删除/调起止

### 字幕

- **时间行为**：按配音逐字时间戳自动拆段（词级拆段：≤18 字、
  标点/停顿优先断），段的显示只认语音时间轴、**完全无视镜头边界**
  ——跨分镜自然连续（整条画面都是自己渲的，无原片硬字幕衔接约束）
- **样式四可调**（2026-08-19 修订：全片默认 + **行级可覆盖**——
  选用的分镜可能自带字幕、位置各不相同，需逐行挪位置避开）：
  1. 垂直位置滑块（预览实时跟随）
  2. 字号滑块
  3. 颜色预设 6 色：白/黄/橙/青/粉/绿（默认黑描边）
