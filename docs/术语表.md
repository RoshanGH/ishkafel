# ishkafel 术语表

> 项目统一话术，所有文档、代码注释、UI 文案均以此为准。
> 更新日期：2026-08-28

| 术语 | 定义 | 备注 |
|------|------|------|
| **台词语义单元** | 以台词语义为准的切分单元。一段完整语义（可能一句台词，也可能多句）构成一个单元，切分依据是"想表达的意思"，以台词为主，不以画面切换为准。 | 口语里叫**分子**；历史别名"逻辑分镜"，已废弃 |
| **视觉镜头** | 台词语义单元内部的实际画面切换单元。一个台词语义单元通常包含多个视觉镜头。 | 口语里叫**原子**；历史别名"分镜头"，已废弃 |
| **成片** | 输入的完整视频（作为依据的原片），来源为本地上传或 miaoa 视频 ID。 | |
| **替换裂变** | 两条生产线之一：以片找片、换画面。有原片时保持台词与结构不变、把画面换成新素材；没有原片时直接从素材拼。工作页是**工作台**。 | 历史别名"成片翻新"，已废弃 |
| **脚本成片** | 两条生产线之一：从台词造新片。台词可以自己写，也可以从一条参考片里提取。配音由 TTS 生成，节奏由配音决定。工作页是**编导台**。 | |
| **工作台** | 替换裂变的工作页：左侧台词语义单元列表、中间预览、右侧候选素材、下方时间线。 | |
| **编导台** | 脚本成片的工作页：逐行写台词、配音、配画面、铺配乐。 | |
| **标签组** | 从 miaoa 拉取的标签的一个分组，作为 AI 打标的受控词表——AI 只允许使用选定组内的标签。 | |
| **候选素材** | 替换某个台词语义单元时，按相同标签从 miaoa 检索出的素材列表，供用户手动挑选，可多选。 | |
| **矩阵导出** | 各台词语义单元所选候选素材的笛卡尔积组合批量导出，上限 100 条。 | |
| **审片台** | 第一版的核心工作模式：全手动逐单元确认/挑选，不做全自动出片。 | |

## 两条线，各有两种起点

**起点（有没有原片）不是模式，只是入口**——同一条线进去之后干的是同一件事。

| | 有原片 | 没有原片 |
|---|---|---|
| **替换裂变**（进工作台） | 上传成片 → 分析切分 → 逐镜换素材 | 不用原片，直接从素材拼 |
| **脚本成片**（进编导台） | 上传参考片 → 提取台词 → 配音配画面 | 直接写台词 → 配音配画面 |

选哪条线，看的是**原片那个人的声音还要不要**：

- 要（台词不动、节奏照着原片来）→ **替换裂变**。用原片的声音，节奏天然一致。
- 不要（台词要改、要换人念、或压根没有原片）→ **脚本成片**。TTS 重念，
  成片长度与原片必然不同，这是结构性的。

## 概念示例

台词"这个东西能把衣服洗干净"是**一个台词语义单元**，它内部可能过了 3 个**视觉镜头**：

1. 展示脏衣服
2. 展示正在洗的状态
3. 展示洗干净的状态

## 数据模型层级

```
成片
 └─ 台词语义单元（台词语义层，以 ASR + LLM 语义分组切分）
     └─ 视觉镜头（画面层，以视觉场景检测切分，按需懒切）
```
