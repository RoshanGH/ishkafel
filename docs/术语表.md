# ishkafel 术语表

> 项目统一话术，所有文档、代码注释、UI 文案均以此为准。
> 更新日期：2026-07-29

| 术语 | 定义 | 备注 |
|------|------|------|
| **台词语义单元** | 以台词语义为准的切分单元。一段完整语义（可能一句台词，也可能多句）构成一个单元，切分依据是"想表达的意思"，以台词为主，不以画面切换为准。 | 历史别名"逻辑分镜"，已废弃 |
| **视觉镜头** | 台词语义单元内部的实际画面切换单元。一个台词语义单元通常包含多个视觉镜头。 | 历史别名"分镜头"，已废弃 |
| **成片** | 输入的完整视频（待翻新的原片），来源为本地上传或 miaoa 视频 ID。 | |
| **成片翻新** | 本平台的核心生产方式：分析成片 → 切分 → 从素材库找同标签素材替换 → 本地合成，产出结构相同但画面全新的视频。 | |
| **标签组** | 从 miaoa 拉取的标签的一个分组，作为 AI 打标的受控词表——AI 只允许使用选定组内的标签。 | |
| **候选素材** | 替换某个台词语义单元时，按相同标签从 miaoa 检索出的素材列表，供用户手动挑选，可多选。 | |
| **矩阵导出** | 各台词语义单元所选候选素材的笛卡尔积组合批量导出，上限 100 条。 | |
| **审片台** | 第一版的核心工作模式：全手动逐单元确认/挑选，不做全自动出片。 | |

## 概念示例

台词"这个东西能把衣服洗干净"是**一个台词语义单元**，它内部可能过了 3 个**视觉镜头**：

1. 展示脏衣服
2. 展示正在洗的状态
3. 展示洗干净的状态

## 数据模型层级

```
成片
 └─ 台词语义单元（台词语义层，以 ASR + LLM 语义分组切分）
     └─ 视觉镜头（画面层，以视觉场景检测切分，按需懒切）
```
