## 布局结构

- 左栏导出设置：输出目录、分辨率/帧率（默认同原片）、编码（H.264 硬件加速）、命名模板 `{原片名}_v{序号}`、并行导出数；音轨策略提示框
- 右栏导出清单：逐行组合——勾选框、序号、缩略图序列（绿框=整体替换素材、紫框=镜头级替换、灰暗=保留原片）、构成摘要（U1·候选A ｜ U3·S1C1+S2C2 …）、时长、状态（完成/进度条/排队）
- 清单工具：全选 / 反选 / 随机抽 N
- 底部：总进度条、预计剩余、产物占用、暂停 / 打开输出目录 / 完成通知

## 暂定策略

- **音轨**：第一版保留原片完整音轨，替换素材仅取画面；声音克隆/换音色后续版本引入（对应架构文档待定问题）
- 组合上限 100 条在阶段②已拦截，本页只对已确定的组合执行导出
