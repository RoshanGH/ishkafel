## 布局结构

- 左栏：已锁定的单元列表，徽标显示各单元模式与因子（整体 ×N 绿 / 镜头级 ×N 紫 / 保留原片 橙）
- 中间：播放器（原片 ⇄ 候选预览 分段控件）
- 右栏候选面板（从上到下）：替换模式三态分段（互斥，镜头级激活时整体替换锁定🔒）→ 视觉镜头条（S1/S2/S3 各带因子）→ 检索方式切换（标签｜画面描述｜首帧搜图，互斥单选，显示查询帧）→ 两列候选大卡（来源、时长与时长差徽标、勾选多选）→ 因子小结
- 底部：单元导航条（各单元因子徽标）+ 组合数状态栏（笛卡尔积 / 上限 100）

## 核心规则

- 两级替换互斥：整体替换 与 镜头级替换 二选一；进入一方另一方锁定
- 组合因子：整体替换 = 候选数；镜头级 = 单元内各镜头候选数乘积
- 检索三模式互斥：标签（受控词表）/ 画面描述语义搜 / 首帧以图搜图，两层通用

## 素材说明

候选素材为另两条滴露成片（植源喷雾_ZJD、自然消毒液_CQX）真实抽帧，模拟 miaoa 同标签检索结果。
