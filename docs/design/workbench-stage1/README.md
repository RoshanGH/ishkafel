## 布局结构

- 顶栏：成片信息（名称/来源/时长/分辨率/两个标签组）+ 三阶段步骤条
- 上区三栏：台词语义单元列表 ｜ 竖屏播放器（窄舞台居中）｜ 属性检查器（跟随选中对象：单元或镜头）
- 双层时间线（主操作区）：语义单元轨（拖大边界）+ 视觉镜头轨（嵌套对齐，拖小边界）+ 抽帧画面轨 + 音频波形轨
- 底部：状态汇总 + 「确认切分，进入替换选材」

## 核心交互规则

- 导入后统一全处理：ASR → 语义单元切分/打标 → 视觉镜头切分/打标，两层全部就绪后进入本页
- 点哪层边界就编辑哪层；镜头边界的移动限制在所属单元范围内
- **所有边界修改帧对齐**（拖拽吸附帧边界、步进 ±1 帧）
- 两层确认后一次性锁定，阶段②不再有切分操作
