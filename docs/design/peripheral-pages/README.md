## 三页要点

1. **任务列表（首页）**：任务卡网格——封面、来源（miaoa #ID / 本地）、状态徽标（分析中带进度 / 待切分确认 / 选材中 / 已导出 N 条）、单元数与组合数；顶栏搜索 + 新建任务
2. **新建任务向导（模态）**：① 选来源（本地拖入 / miaoa ID 拉取+预览确认）② 选两个标签组（语义单元组 + 视觉镜头组，展开显示组内标签预览）→ 开始分析（自动 ASR → 两层切分/打标，预计 2–4 分钟）
3. **设置页**：分区导航——miaoa 账号（登录/租户/项目/检索范围）、AI 服务、导出默认、缓存管理、关于
