# 脚本成片（编导台）——实现分期计划

> 依据：[设计讨论记录](./2026-08-19-脚本驱动生产模块-设计讨论.md)（已定稿）
> 原则：每个里程碑真机可验收、可发版；先让核心体验闭环（手写脚本 →
> 配音 → 配镜 → 预览），复刻链路是放大器、随后接入

## M1 骨架：任务与编导台（已完成，0.1.16–0.1.17）

- 新建任务第四张卡「脚本成片」+ 选标签组（沿用现有选择器）
- 数据模型：脚本行（类型/文案/状态/标签/音色引用/镜头位…），
  复用现有任务仓储、锁、产物清单设施
- 编导台三栏页：左栏脚本编辑（回车新行 / 空行即画面行 / 行状态点 /
  拖动排序 / 删除），中栏预览占位，右栏行工作台骨架
- **从视频提取脚本**（原排 M5，应用户要求提前）：上传参考成片 →
  ASR → AI 语义断句成行；空脚本起步引导给「提取 / 直接写」两条路
- 任务短编号（#N）：任务卡与编导台顶栏展示、搜索直达、CLI 全线支持
  （顺手全局能力，非本模块专属）
- **验收**：建任务 → 写十行脚本 → 关掉重开不丢 → 行操作全可用；
  传一条有口播的成片 → 脚本行自动长出来

## M2 配音链路

- 火山音色库拉取与试听；行级音色选择（头像微标 + 面板）
- 「生成配音」显式触发（改台词后状态变黄、旧配音可听）；
  逐字时间戳随配音落盘（后续字幕用）
- 行级语速；配音时长即行时长；试听
- **验收**：一行文案 → 选音色 → 生成 → 试听；改文案 → 状态提示 →
  重新生成 → 新时长生效

## M3 找镜头与镜头序列

- 行台词打标（U 层打标管线复用），标签挂行、可改删
- 找镜头面板：顶部标签栏（预填可编辑）+ AI 候选（自动预搜）+
  画面描述搜 + 以图搜；候选防撞车标注
- 挑选落地（素材下载固定，复用 PickedMediaCache）；镜头序列卡 +
  悬停即播
- **验收**：一行配上两三个镜头，候选来自 miaoa 真实检索

## M4 时长分配与预览

- 镜头位胶片条：框选区间（不必从头）、显式变速（变速清框重选）、
  邻镜联动总长锁死、0.5s 阈值、可用量警告
- 行级预览（配音 + 镜头序列）与中栏整片预览（edl 拼接，复用预览管线）
- **验收**：6 秒配音三个镜头，框选/变速/联动全可操作，预览所见即所得

## M5 复刻链路（放大器）

- 上传整片参考 → ASR → AI 语义断句成行 → 两层自动打标 →
  参考分镜切分（帧信号管线复用）→ 每镜自动预搜候选 = **完整草片**
- 行级参考视频上传（原创行同样可用）；「按参考重新配镜」确认覆盖
- **验收**：传一条滴露成片，两分钟后得到一版可试听可换镜的草片

## M6 BGM、字幕与导出

- BGM：左栏拖选行区间铺设、行侧色带、相邻同曲连续（引擎复用）
- 字幕：全局「字幕」卡（位置/字号/6 色/模糊遮罩开关）+ 行级覆盖；
  按配音逐字时间戳拆段、跨镜连续
- 导出单条成片（渲染管线复用；交付拦截照旧）
- **验收**：完整走完「脚本 → 成片」一条，导出物人工验收

## M7 收尾与增强

- 上传声音克隆自定义音色
- 链行（相邻行共用镜头组）；角色标签（话术标签组自动打）
- 画面行完整支持（手填时长 / 随素材、素材原声）
- 配音行素材原声垫底开关
- **验收**：设计稿全项对照打勾
