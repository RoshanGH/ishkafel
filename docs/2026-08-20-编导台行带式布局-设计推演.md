# 编导台「行带式」布局——二十轮设计推演

> 起因（用户原话，2026-08-20）：「我每点一左边的一段对话，右边会进行切换。
> 我不要这样……右边应该像参考图一样，和左边一样排下来的，一块一块对应
> 左边的台词。视频是具有连贯性的……不能一个一个去切换，里面的内容去切换
> 没问题。」以及：「ASR 切出来的分子原子要在右边有一列展示，作为参考视频。」
>
> 结论先行：**废掉 master-detail（选中行→右栏检查器切换）**，右栏改为
> 「分镜编辑板」——所有行的工作块从上到下铺开，一块对应一行台词；
> 每块内含参考段卡、镜头序列、配音状态。以下是推演过程的留痕。

## 推演记录（每轮：质疑 → 决策）

1. **范式**。检查器（Xcode/FCP inspector)适合「属性多、对象一次看一个」；
   视频行是**序列**，人审片是从上往下扫。→ 行带列表（即剪同构）。
2. **左栏去留**。即剪左栏只是只读文案；我们的主张是「脚本是唯一真相」，
   左栏是写作区。合并进右栏会让写作和配镜挤在一个块里互相打架。
   → 左栏保留（可编辑、轻），右栏块里的台词**只读**，点击聚焦左栏该行。
3. **编辑入口唯一性**。台词若两处可编辑，光标/防抖/焦点三方打架。
   → 只有左栏能改字。右栏块顶的台词是「这块在为哪句话工作」的标题。
4. **三栏还是两栏**。预览必须常驻（改完立刻看）。→ 三栏保留：
   左 = 脚本（280）、中 = 预览（定宽 400，播放器窄而居中）、
   右 = 分镜编辑板（flex，镜头卡横排需要宽度）。
5. **参考列的本质**。用户上传成片提取脚本时，每句的原片区间（ASR
   时间戳）就是这一行的「参考视频」。→ 行挂 `reference{startMs,endMs}`，
   视频路径跟文档走（`ScriptDoc.refVideoPath`）。提取时自动落。
6. **参考卡放哪**。即剪把参考分镜直接混进镜头列。单独一列会把块切碎。
   → 参考卡放镜头序列**最左位**，虚线边框+「参考」角标区分；不进成片。
7. **参考卡的动作**。只能看太浪费——参考段本身就是可用画面（原片是
   本地文件）。→ 参考卡给「用它」：一键把该区间填成本行第一个镜头
   （source=原片, trim=startMs, 时长=区间长）。
8. **参考段怎么看**。点缩略图弹小播放器循环播该区间；缩略图取区间
   中点帧（两端常踩转场）。抽帧按 (视频,行) 指纹缓存，不重复跑 ffmpeg。
9. **镜头详情去哪**。原右栏的时长/起点/速度面板不能再「切换」。
   → 点镜头卡在**块内向下展开**详情条（内容切换发生在块内——用户明确
   允许），再点收起。一次只展开一个块的一个卡。
10. **配音控件密度**。整套（音色/语速/生成/试听/状态）摊开每块太重。
    → 块底一条紧凑「配音行」：状态点+音色名+时长+生成/试听按钮；
    语速与换音色收进音色名的弹出菜单。
11. **找镜头入口**。留在块内（每块一个「找镜头/增删」），面板照旧弹层。
12. **滚动联动**。强制同步滚动在行高不等时是灾难（两边跳）。
    → 各自滚动；点左栏行→右板 ensureVisible 对应块；点右板块→左栏选中。
13. **预览联动**。即剪「点句子跳播」。→ 轨道构建返回每行的预览轴起点
    （lineStarts），点块 seek 到行起点；行未进预览则不跳（块上本来就有
    未就绪原因）。
14. **状态可见性**。每块自己说清：没配音（生成按钮就位）、没镜头
    （找镜头引导）、素材下载中/失败（卡上角标）、分配缺口（橙字）。
    中栏「第 N 行未进预览」的汇总保留——两处口径同源（skippedLines）。
15. **性能**。几十行×每行几张网络缩略图：右板用 ListView.builder 惰性
    构建；参考缩略图本地缓存；镜头缩略图沿用 Image.network（M3 已有）。
16. **排序**。拖拽排序只留左栏（右板块重、拖起来笨）。删行也在左栏。
    块内只管「这一行的内容」。
17. **空行（画面行）块**。没台词不代表没块——画面行块标题显示
    「画面行 · 手填 X 秒/随素材」，时长输入收进块内，镜头序列照常。
18. **起步引导**。空脚本时中+右合并为引导舞台（原样保留 StartGuide），
    有内容后右板出现。
19. **选中语义**。行选中仍存在（左右互相高亮、键盘上下文），但不再
    驱动任何「切换」——它只是「你正看着哪一行」的标记。
20. **迁移**。旧任务没有 reference——参考位自然缺席，块布局不变；
    检查器旧交互彻底移除，无兼容负担（模块未对外发布过整体验收）。

## 定稿结构

```
┌──────────┬────────────┬──────────────────────────────┐
│ 脚本(280) │ 预览(400)  │ 分镜编辑板 (flex)              │
│ 可编辑    │ 播放器+传输 │ ┌─ 块1: 台词(只读)·状态 ────┐ │
│ 拖拽/删行 │ 未进预览点名│ │ [参考][镜1][镜2][+找镜头]  │ │
│          │            │ │ ▼ 展开的镜头详情(块内)      │ │
│          │            │ │ ♪ 配音: 状态·音色·时长·生成 │ │
│          │            │ └───────────────────────────┘ │
│          │            │ ┌─ 块2 … ────────────────────┐ │
└──────────┴────────────┴──────────────────────────────┘
顶栏：#编号 名字 | 保存状态 | 配乐 字幕 | 提取 | 导出
```

## 数据改动

- `ScriptDoc.refVideoPath: String?`（提取来源视频，跟文档走）
- `ScriptLine.reference: LineRef{startMs,endMs}?`（该句在参考片里的区间）
- `ScriptTranscriber` 返回行时带上时间戳
- `ScriptPlanResult.lineStarts: Map<int,int>`（行→预览轴起点，跳播用）
