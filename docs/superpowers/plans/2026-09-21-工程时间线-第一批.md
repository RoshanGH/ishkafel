# 工程时间线 · 第一批（对外统一说帧）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「时间 → 帧」收敛成唯一一条路，并让对外的成片位置一律用帧 + 时间码说话。**产品行为不变**（导出的片子、界面操作一个字不改）。

**Tech Stack:** Dart / Flutter；测试 `flutter test`；已有件 `ComposedFrames`（`lib/core/timeline/composed_frames.dart`）、`FrameSpan`（`lib/core/editing/frame_time.dart`）、`Rational`（`lib/core/time/rational.dart`）。

### Task 1: 「时间 → 帧」收敛成一个函数

spec §3.3「舍入规则写死，只此一处」。

```dart
  /// **唯一的「时间 → 帧」。** 整个时间线上，任何把毫秒变成帧号的地方都走这里。
  ///
  /// 取最近帧（`round`）——它离人和 AI 的本意最近。但取 `round` 还是 `floor`
  /// 其实无关紧要，**要紧的是所有边界走同一个函数**（见 [spanOfMs]）。
  int frameAtMs(int ms) => frameIndex(ms, _fps);

  /// 一段时间在轴上占哪几帧，**闭区间**。
  ///
  /// `[frameAtMs(起), frameAtMs(止) - 1]`——两端走同一个函数，于是相邻两段
  /// **天然不共享帧、也不留空隙**：前一段的末帧 + 1 就是后一段的首帧。
  ///
  /// 2026-09-20 那个「相邻词 375/487 共享同一帧」的 bug，成因不是舍入方式
  /// 选错了，是**段头和段尾走了不同的处理**——`FrameSpan.fromMs` 只在段尾做了
  /// 「回退到严格早于 endMs」的修正，段头直接四舍五入。当时是拿一个 while
  /// 循环把段头往前顶回来；那是补丁，这里是规矩。
  ///
  /// 为什么不去改 `FrameSpan.fromMs`：它还被播放器逐帧步进、时间线编辑、
  /// mpv 播放用着，动它要跑预览体检（`scripts/preview_health.sh`）。
  ///
  /// 守这条纪律的架构测试在
  /// `test/architecture/subtitle_ms_to_frames_one_path_test.dart`。
  FrameSpan spanOfMs(int startMs, int endMs) {
    final first = frameAtMs(startMs);
    final last = frameAtMs(endMs) - 1;
    return FrameSpan(first: first, last: last < first ? first : last, fps: _fps);
  }
```

把原来 `frameAt` 的定义删掉，测试里对 `frameAt` 的调用改成 `frameAtMs`（**只改调用名，断言一个字不改**）。

/// 时间线上的一段，**闭区间，只能由 [ComposedFrames] 产出**。

/// 构造函数私有是故意的：下游拿不到别的造法，于是「自己算一个帧号凑一段」
/// 从「靠纪律不做」变成「编译不过」。
///
/// 2026-09-20 的教训：`ComposedFrames` 当时已经把段头对称补好了，但那个
/// 方法是私有的、没给下游留出口，于是两处下游退回裸调 `frameAt` /
/// `FrameSpan.fromMs`——对称性在真正要用它的地方全丢了，真机上 487 对
/// 相邻词有 375 对共享同一帧。补一条扫字符串的架构测试也没拦住（它漏了
/// `frameAt`）。**靠类型，不靠纪律。**
///
/// 同一个形状的先例：`preview_segments_share_one_spec_test`
/// 「那个类型只能由闸产出——构造函数必须是私有的」。
class TimelineSpan {
  /// 第一帧（含）
  final int first;

  /// 最后一帧（含）。**相邻段不共享任何一帧**：前一段的 last + 1 就是
  /// 后一段的 first
  final int last;

  const TimelineSpan._(this.first, this.last);

  int get frameCount => last - first + 1;

  @override
  String toString() => 'TimelineSpan($first..$last)';
}
```

```
